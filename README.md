# elf-violet

A Claude desktop theme inspired by an original VRChat avatar: a black-haired elf with violet inner color, violet-rimmed glasses, a black jacket with violet piping and a wine-red tie. Dark charcoal and lavender-white surfaces, violet accent, wine-red for errors, a slow backdrop of violet trim lines, and a small chibi face with a sleepy, sharp-tongued line on the working row of the desktop app.

## Install

In a terminal session:

```
/plugin install elf-violet --marketplace PepeWeekend/claude-theme-elf-violet
```

Answer `y` to add the marketplace, then choose the user scope.

From a shell:

```
claude plugin install elf-violet --marketplace PepeWeekend/claude-theme-elf-violet
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with `PepeWeekend/claude-theme-elf-violet`, then Add plugin.

If this repository is private, the machine needs a git credential for github.com (`gh auth login`, then `gh auth setup-git`).
